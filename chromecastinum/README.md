# Chromecastinum

Браузер для Windows на движке Chromium (Electron), который **вообще не сохраняет
куки** — а также историю, кэш, localStorage и любые другие данные сайтов.

## Как это гарантируется

| Механизм | Что даёт |
|---|---|
| In-memory сессия (partition без `persist:`) | Куки и хранилища сайтов существуют только в оперативной памяти — на диск не пишутся никогда |
| `--disable-http-cache` | Отключён дисковый HTTP-кэш |
| Профиль во временной папке | Служебные файлы Electron уходят в `%TEMP%` и удаляются при выходе (плюс зачистка остатков при следующем запуске) |
| `clearStorageData()` при выходе | Дополнительная страховка: всё стирается ещё до закрытия |
| Запрет разрешений | Уведомления, камера и микрофон запрещены; геолокация — только когда вы сами задали фейковые координаты |

Пока браузер открыт, куки работают в памяти — можно логиниться на сайты.
Закрыли окно — всё исчезло, как будто вы там никогда не были.
Кнопка 🧹 на панели стирает куки и данные всех сайтов мгновенно, не закрывая браузер.

## Маскировка под обычный Chrome

По умолчанию Electron сообщает сайтам User-Agent со словами `Electron` и именем
приложения, и антибот-системы (Akamai, Cloudflare и т.п.) по ним сразу блокируют
браузер. Chromecastinum этого не допускает:

- User-Agent подменяется на строку настоящего Chrome для Windows (с реальной
  версией движка Chromium).
- Client Hints (`sec-ch-ua`, `navigator.userAgentData`) очищаются от бренда
  `Electron`.
- Прячется признак автоматизации `navigator.webdriver`.

Благодаря этому сайты вроде adidas, Nike и подобных пускают без страницы
«security issue».

> ⚠️ Важно: подмена местоположения меняет только координаты и время, которые видит
> сайт через JavaScript, **но не ваш IP-адрес**. Чтобы сменить и IP (страну по IP),
> используйте прокси — см. ниже.

## Прокси-профили 🔌

Кнопка 🔌 на панели открывает менеджер прокси. Можно **добавить сколько угодно
профилей** и переключаться между ними одним кликом — активный прокси применяется
ко всем вкладкам и меняет ваш видимый IP-адрес.

- Поддержка **HTTP, SOCKS5, SOCKS4**.
- Логин и пароль (авторизация на прокси подставляется автоматически).
- Клик по профилю сразу включает его и перезагружает вкладки; строка «Без прокси»
  возвращает прямое соединение.
- Профили **сохраняются между запусками** (в `%APPDATA%\Chromecastinum\proxies.json`) —
  это настройка, а не данные слежки, поэтому она переживает очистку куки.
- При переключении сбрасываются старые соединения и авторизация, чтобы прокси
  применился «начисто».

Так связка работает вместе: прокс­и США даёт американский IP, а ZIP-код —
совпадающие с ним геолокацию и время. Для сайтов вы выглядите как реальный
пользователь из США.

## Местоположение США по ZIP-коду 🇺🇸

Кнопка 🇺🇸 на панели открывает окно, где нужно ввести **почтовый индекс (ZIP-код)
США** — остальное происходит автоматически:

- По ZIP-коду определяются город, штат и координаты (офлайн-база, пакет `zipcodes`).
- Часовой пояс вычисляется по этим координатам (офлайн-карта, пакет `tz-lookup`) —
  корректно для всех штатов, включая Аризону без перехода на летнее время, Индиану,
  Аляску, Гавайи и пограничные ZIP-коды.
- Сайты видят координаты этого места, а **время браузера (`Date`, `Intl`) подстраивается
  под его часовой пояс**.
- «Применить» — вкладки перезагружаются; «Сбросить» — вернуть реальные данные.

Всё работает офлайн — ZIP-код никуда не отправляется. Геолокация отдаётся сайту только
когда ZIP задан; без этого запрос местоположения отклоняется. Подмена реализована через
штатную эмуляцию Chromium (тот же механизм, что в DevTools).

Примеры: `90210` → Beverly Hills, CA (Тихоокеанское время) · `10001` → New York, NY
(Восточное) · `60601` → Chicago, IL (Центральное) · `85001` → Phoenix, AZ.

## Возможности

- Вкладки (Ctrl+T — новая, Ctrl+W — закрыть, средняя кнопка мыши — закрыть)
- Адресная строка с поиском DuckDuckGo (Ctrl+L — фокус)
- Назад / вперёд / обновить (F5)
- Ссылки `target="_blank"` открываются новой вкладкой
- Местоположение и время США по ZIP-коду (кнопка 🇺🇸)
- Прокси-профили HTTP/SOCKS с переключением одним кликом (кнопка 🔌)

## Установка (проще всего)

1. Установите [Node.js](https://nodejs.org) — кнопка **LTS**, дальше Next → Install.
2. Двойной клик по **`Установить.bat`** (один раз).
3. Двойной клик по **`Запустить.bat`** — браузер откроется.

Для портативного `.exe` — **`Собрать-EXE.bat`**, файл появится в `dist\Chromecastinum.exe`.

## Запуск через командную строку (для тех, кому так удобнее)

```bat
cd chromecastinum
npm install
npm start
```

## Сборка одного .exe для Windows

На Windows-машине:

```bat
cd chromecastinum
npm install
npm run dist
```

Готовый портативный файл появится в `chromecastinum/dist/Chromecastinum.exe` —
его можно просто скопировать и запускать без установки. У `.exe` и окна будет
фирменная иконка из `build/icon.ico`.

## Иконка

Иконка приложения лежит в папке `build/`:

- `icon.ico` — многоразмерная иконка для Windows (16–256 px), её использует
  и окно браузера, и собранный `.exe`.
- `icon.png` — превью 1024×1024.
- `icon.svg` — исходник (глобус с булавкой местоположения на тёмной плитке).
