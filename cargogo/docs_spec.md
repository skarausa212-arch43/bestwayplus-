# CARGOGO — ПОЛНОЕ ТЕХНИЧЕСКОЕ ЗАДАНИЕ ДЛЯ CLAUDE CODE

## 1. Цель проекта

Создать MVP мобильного приложения для заказа грузовых перевозок по Польше.

Приложение работает по принципу Uber или Bolt, но предназначено для:

- перевозки мебели;
- переездов;
- доставки бытовой техники;
- перевозки палет;
- перевозки строительных материалов;
- перевозки автомобилей и мотоциклов;
- перевозки других крупногабаритных грузов.

В приложении должно быть три роли:

1. Клиент.
2. Водитель.
3. Администратор.

На первом этапе создать полнофункциональный демонстрационный MVP с mock-данными и рабочими переходами между экранами.

Рабочее название проекта:

**CargoGo**

Название должно храниться в одном конфигурационном файле и легко заменяться.

Основной язык интерфейса:

**польский**

Архитектура должна позволять добавить:

- русский;
- английский;
- украинский;
- белорусский;
- немецкий.

# 9. Тип транспорта

Предусмотреть три основных типа.

## 9.1. Mały bus

Описание:

**Drobne przeprowadzki, AGD, meble, paczki i niewielkie ładunki.**

Пример:

- длина кузова до 3 м;
- ширина до 1,8 м;
- высота до 1,9 м;
- грузоподъёмность до 1000 кг.

## 9.2. Duży bus

Описание:

**Większe przeprowadzki, palety, duże meble i większe ładunki.**

Пример:

- длина кузова до 4,5 м;
- ширина до 2,1 м;
- высота до 2,2 м;
- грузоподъёмность до 1500 кг.

## 9.3. Laweta

Описание:

**Transport samochodów, motocykli i niesprawnych pojazdów.**

Дополнительные поля:

- марка машины;
- модель;
- масса автомобиля;
- исправен ли автомобиль;
- может ли автомобиль самостоятельно заехать;
- заблокированы ли колёса;
- фото автомобиля.

# 13. Оплата

Способы оплаты:

- Apple Pay;
- Google Pay;
- BLIK;
- карта;
- сохранённая карта;
- оплата компанией;
- счёт-фактура для фирмы.

Для фирмы добавить:

- название фирмы;
- NIP;
- адрес;
- e-mail для фактуры.

В MVP использовать тестовую оплату.

Логика:

1. Сумма предварительно блокируется.
2. После завершения заказа списывается итоговая сумма.
3. При изменении цены клиент получает уведомление.
4. Изменение цены должно требовать подтверждения клиента, кроме заранее оговорённых доплат.
