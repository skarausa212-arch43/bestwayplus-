# CargoGo — MVP aplikacji do przewozów towarowych (Polska)

Uber/Bolt dla transportu: meble, przeprowadzki, AGD, palety, materiały budowlane, **laweta** (auta i motocykle).

## Роли
- **Клиент** — заказ, оплата (mock), трекинг, чат, оценка, чаевые
- **Водитель** — 8-шаговая регистрация с документами, mock-модерация, Online/Offline, приём заказов с таймером, смена статусов, код подтверждения, заработок
- **Админ** — dashboard, водители, заказы, тарифы (mock-панель)

## Уведомления (ключевая фича)
Каждое событие рождает уведомление у нужной роли:
- **системный push** (expo-notifications, локальный — имитирует серверный),
- **in-app toast-баннер** поверх экрана,
- запись в **центре уведомлений** (🔔 с бейджем непрочитанных).

Клиент получает: водитель найден / едет / на месте / загрузка / в пути / доставлено / оплата / отмена.
Водитель получает: новый заказ / отмена / сообщение / чаевые / оценка / аккаунт одобрен / выплата.

## Запуск
```bash
npm install
npx expo start
```
Открыть в Expo Go (iOS/Android) или симуляторе.

## Демо-сценарий (одно устройство)
1. Войти клиентом → создать заказ (5 шагов) → mock-оплата → «Szukamy kierowcy» → через 4 с водитель принят автоматически → трекинг, чат, статусы.
2. Разлогиниться → войти водителем → Online → принять входящий заказ (таймер 20 с) → прокликать статусы до «Rozładunek zakończony» → ввести код **4217** → заработок в «Zarobki».
3. Код подтверждения клиент видит на экране активного заказа.

## Архитектура
- `src/config/app.ts` — название и параметры (легко переименовать)
- `src/i18n/` — локализация (pl полный; ru/en/uk/be/de добавляются файлами)
- `src/theme/` — дизайн-система (colors, spacing, typography, radius, shadows)
- `src/types/` — все сущности из ТЗ (§51)
- `src/store/` — Zustand: auth, orders (машина статусов + автоуведомления), driver, notifications
- `src/services/notifications.ts` — единая точка `notify(role, title, body)`
- `src/components/MockMap.tsx` — mock-карта; интерфейс готов под замену на Mapbox/Google Maps

## Что mock (по §59 ТЗ)
Платежи, SMS/e-mail верификация, OCR документов, банковская проверка, реальная карта/GPS, серверный push, алгоритм распределения. Всё изолировано и готово к замене на реальные сервисы.

## Что добавлено при доводке MVP (перенос логики из HTML-прототипа)

### i18n на 3 языка + заглушки
- `src/i18n/pl.ts` / `ru.ts` / `en.ts` — полные словари (структура совпадает, тип `Dict` это гарантирует), `uk/be/de` — заглушки с фолбэком на pl.
- **У каждой роли свой язык** (`src/store/locale.ts`, persist): переключатель PL/RU/EN (+uk/be/de) в профиле клиента и водителя.
- Уведомления хранятся ключами (`titleKey/bodyKey/params`) и рендерятся **на языке роли-получателя** (`renderNotifTitle/renderNotifBody`).

### Автоперевод чата
- Быстрые фразы = ключи словаря `q.0..q.5` — мгновенный перевод без сети.
- Свободный текст = `{text, lang, tr:{pl,ru,en}, pending}` как в прототипе; перевод через Claude API (`src/services/translate.ts`), пометка «🌐 переведено».
- Ключ API не хардкодится (§59): без ключа перевод тихо отключается, показывается оригинал. Для демо: `EXPO_PUBLIC_ANTHROPIC_KEY=sk-... npx expo start`. В production — вызов через свой backend.

### Платное ожидание (§36)
- На статусе `driver_arrived` — таймер 10 бесплатных минут, затем 2 zł/мин.
- Баннер у обеих ролей (`WaitBanner`), уведомление обеим при переходе на платное, доплата в `price.waiting` и `total` при смене статуса.
- Тик = 60 000 мс (prod, `WAIT_TICK_MS` в `src/constants`); в прототипе для демо было 3 с.

### Изменение цены водителем (§37)
- Форма у водителя (сумма + причина) на экране активного заказа.
- Карточка «принять / отклонить» у клиента; уведомления обеим сторонам (`sendPriceReq/answerPriceReq`).

### Остальное
- **AsyncStorage-персистентность**: zustand `persist` для orders / driver / notifications / locale — состояние переживает перезапуск (таймер ожидания возобновляется).
- **Доп. остановки (до 3)** в мастере заказа, тарифицируются (+15 zł/шт), видны водителю и в деталях.
- **Экран деталей заказа** из истории: маршрут, груз, разбивка цены (вкл. ожидание), история статусов.
- `eas.json` для сборки iOS: `eas login && eas build --platform ios --profile preview` (секреты — через `eas secret`).
